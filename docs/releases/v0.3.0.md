# OmniDrop v0.3.0 Alpha — Self-contained Windows x64 Portable

OmniDrop v0.3.0 Alpha is a Windows 10/11 x64 portable development preview.
It retains the v0.2.0 file actions, Qt drag-and-drop UI, CLI, visual Workflow builder,
local Jobs and opt-in folder watching, and removes the requirement to install Python separately.

## New in v0.3.0

- **Bundled CPython 3.13.16:** official Windows amd64 embeddable runtime at `runtime/python/`,
  verified at packaging against the pinned official-archive SHA-256.
- **ABI-matched worker dependencies:** packaged Pillow and pypdf wheels tested using the
  bundled interpreter, including Pillow's native image extension.
- **Single runtime resolver:** Qt GUI, CLI and Workflows prefer the packaged Python executable;
  explicit `OMNIDROP_PYTHON` overrides remain available for advanced usage.
- **Isolated runtime:** `python313._pth` prevents user site, registry and `PYTHONPATH`
  from silently replacing packaged modules.
- **Provenance verification:** GitHub issues a Sigstore-backed SLSA build attestation
  for the Windows ZIP on canonical main-branch CI. The release publisher verifies the
  ZIP hash, producing workflow and exact main commit before publishing.
- **Authenticode-ready workflow:** Windows EXEs can be signed with an owner-supplied
  trusted code-signing certificate; signing secrets are accessible only to the signing step.

## Download and run

Download both assets:

- `OmniDrop-0.3.0-windows-dev.zip`
- `OmniDrop-0.3.0-windows-dev.zip.sha256`

Verify the SHA-256 locally, extract into a dedicated folder **outside any Git checkout**,
and launch `OmniDrop.exe`. No Python installation, account or cloud service is needed
for core file operations. The portable app does not register itself as a Windows installer.

To independently verify the signed GitHub build provenance, install GitHub CLI
and run:

```powershell
gh attestation verify .\OmniDrop-0.3.0-windows-dev.zip --repo stloendays/OmniDrop-Alpha --signer-workflow stloendays/OmniDrop-Alpha/.github/workflows/build.yml
```

## Signature and security limitations

**Signed build provenance is not a Windows Authenticode signature.** Without a publicly
trusted code-signing certificate, `OmniDrop.exe` and `omnidrop-cli.exe` remain
**unsigned Windows binaries** and Microsoft SmartScreen warnings may appear.
This Alpha is **not a signed MSI/MSIX installer** or production-stable release.

The v0.2.0 assets remain unchanged (and still require a system Python).
Optional Piper voices/runtime and Argos language packs are not included.
Translation uploads require explicit approval; local processors do not upload files.
Workflows do not execute arbitrary shell commands.

## Compatibility and validation

- Stable Python Worker v1 protocol, Action IDs, CLI commands and Workflow schema retained.
- No retroactive modification of existing saved Jobs or source files.
- Windows CI runs native CTest and Python tests, plus packed runtime import checks,
  worker-ping and capability checks with system Python removed from PATH, workflow
  execution, and primary/secondary GUI startup tests.
- Linux continues to receive core and Python-worker CI tests; no supported Linux desktop
  package ships in this release.
- No automatic update/rollback, general-purpose office editing, unrestricted scripting,
  OCR, or full multimedia editing is claimed.
